# Yea playbooks

Every way of running a business we have built for real, written down so the generator can pick one and so a person can read it. Each archetype is a business model; each play is one thing we built that works, with the file that does it.

The machine-readable map lives in the postscarcity-ai repo at `lib/yea-finale/playbooks/`. These pages are generated from it by `scripts/yea-playbooks-docs.ts`. Edit the TS, then regenerate. `scripts/yea-playbooks-check.ts` proves every cited file exists.

Rule: no invented capabilities. If a play has no file behind it, it is not a play. Each archetype also lists what is not proven yet.

## How the pick works

`pickArchetype(text)` matches whole words from the business description and site text against each archetype's signals (count 2) and its plays' signals (count 1). It returns the archetype, the words that matched, the runner-up and the plays ranked by fit. The model pass gets this as a starting point and may overrule it with a reason. `playbookBrief(id)` gives the model the archetype in compact form.
