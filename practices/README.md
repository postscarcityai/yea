# Practices

What we learned running a company on agents and building these apps for real businesses. The PRDs say what to build. This says how to run it, and what will bite you.

- **[running-agents.md](running-agents.md):** the operating model. How work gets captured, assigned, reviewed and watched, and how a person stays in charge without reading everything.
- **[traps.md](traps.md):** specific failures we hit, what they looked like and the fix.
- **[learnings/](learnings/):** lessons sent back by other builds, waiting to be folded into traps.md.

Rule: the same as the playbooks. No invented lessons. Each one happened to us. Client details are removed.

When a trap costs you real time, write it down in your own repo's `docs/learnings.md`. If it would help others, and the owner says yes, send it back as a pull request: [`CONTRIBUTING.md`](../CONTRIBUTING.md).
